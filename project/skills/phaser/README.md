# KidsHabits Phaser 4 Skill Library

This folder is the project-local reference library for building KidsHabits with Phaser 4.

Start every substantial Phaser task with **[CATALOG.md](./CATALOG.md)**, choose the relevant skill(s), then read their `SKILL.md` files before implementation.

The library contains the full uploaded Phaser skill set, including game design, architecture, QA, scenes, cameras, animation, tweens, particles, PostFX, responsive mobile layout, input, audio, asset loading, and rendering guidance.

## Project rule

KidsHabits starts clean on **Phaser 4**. We do not preserve Phaser 3.90 compatibility or carry forward implementation constraints from the previous KidsLive prototype.
